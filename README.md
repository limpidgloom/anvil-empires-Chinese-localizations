# anvil-empires-Chinese-localizations_铁砧帝国汉化
游戏开发商开发商 _“Siege Camp”_ 制作了中世纪经营生存多人战争游戏《铁砧帝国》。  
此库中的mod适配对该游戏的中文本地化和兼容中文🇨🇳和日文🇯🇵字符

Game developer _"Siege Camp"_ created *Anvil Empires*, a medieval management, survival, and multiplayer warfare game.   
The mods in this repository provide Chinese localization for the game and ensure compatibility with both Chinese and Japanese characters.

### 说明：
如果你只希望看懂玩家头顶名字和聊天栏里的汉文和日文，而不希望游戏内文本被翻译为汉文，那么你安装：```“Anvil-CharacterCompatibility_字符兼容.pak”```。  
如果你额外希望游戏内UI的文本被翻译为汉文，那么你就只需要安装带有 **“汉化”** 二字的```.pak```文件，而不需要安装上一个。  
### Guide:
If you only want to be able to read Chinese and Japanese characters that appear above players' heads or in the chat box—without having the in-game text itself translated into Chinese—then install ```"Anvil-CharacterCompatibility_字符兼容.pak"```.  
If you also want the in-game UI text to be translated into Chinese, you only need to install the ```.pak``` file that contains the characters **"汉化"** (Chinese translation) in its name; there is no need to install the previous one.

### 安装方法：
在屏幕右侧的 **"Releases"** 里找到所需文件，下载，解压  
把```.pak```文件拖到游戏目录的Paks文件内就好  
### Installation Method: 
Simply drag the ```.pak``` file into the 'Paks' folder within your game directory.   
Locate the required file under **"Releases"** on the right side of the screen, then download and extract it.
