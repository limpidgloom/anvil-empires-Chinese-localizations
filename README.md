# anvil-empires-Chinese-localizations
游戏开发商开发商“Siege Camp”制作了中世纪经营生存多人战争游戏《铁砧帝国》。此mod适配对该游戏的中文本地化和兼容中文和日文字符

Game developer "Siege Camp" created *Anvil Empires*, a medieval management, survival, and multiplayer warfare game. This mod provides Chinese localization for the game and adds support for both Chinese and Japanese characters.
